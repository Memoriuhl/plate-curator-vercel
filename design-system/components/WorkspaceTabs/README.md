# WorkspaceTabs

The workspace switcher, centred in the header: Dashboard, Review (with a count of batches waiting) and Strip Art. The active tab is a `primary` pill on a `fill` track. Inbox is not a tab; it is an icon at the top right beside the profile. Code: `components/app/workspace-tabs.tsx`, built as links (each workspace has its own URL) styled with shadcn Tabs.
