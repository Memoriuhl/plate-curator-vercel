# StatusIcon

One of the seven plate checks, as a bare `icon-status` glyph with no tile. The checks are always in this order: description, fun facts, link, tags, family, image, rarity.

- **Good:** the plain glyph in `success`.
- **Weak:** adds a dot, in `warning`.
- **Missing:** slashed, in `danger`.

Hover or focus shows the full value. Completeness is a label and never blocks anything. Code: `components/plate/status-icon.tsx`.
