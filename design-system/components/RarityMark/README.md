# RarityMark

Rarity as the diamond in its tier colour (`rarity-1` Local to `rarity-6` Holy Grail).

- **Outline:** Estimated, the default.
- **Filled:** Observed from real sightings.
- **Dashed:** Manual, a curator override. A Manual tier always offers **Remove** and **Use estimated**, so an override never passes for data.

Code: `components/plate/rarity-mark.tsx` (shadcn Popover for the override menu).
