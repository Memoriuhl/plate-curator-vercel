# FilterChip

A toggle chip with a count. "On" is a `primary` fill. "Off" is `card` on the ground, or `fill` inside a card. Health checks such as "No fun facts" use the same chip with their status icon in its meaning colour: click shows those plates, Shift-click selects them all for a run. Code: `components/ui/toggle.tsx` (shadcn Toggle, `aria-pressed`).
