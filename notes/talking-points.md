# Demo talking points

- Find image offers inspectable Commons photos with provenance. Choosing one feeds the rest of the run; applying the completed run is a separate action.
- Group uses the existing DINO implementation with real mask and colour options. It processes the selected complete families, not an entire state hidden behind a plate selection.
- Preview results are inspect-only and cannot be applied later. Rerun normally to apply; normal runs use explicit aggregate Apply with original revision checks.
- Standard and state order stay in place. Order is the existing manual drag flow.
- Remote image overrides are draft-only until the managed staging upload follow-up. No publish, deploy or production worker changes are part of this work.
- Research / enrich captures bounded evidence before one synthesis call, persists its model choice and reports a visible no-result without inference when sources are absent. The local browser/SDK proof used substitute inference; actual hosted execution remains a separate capped live gate in `docs/eve-pipeline-demo.md`.
